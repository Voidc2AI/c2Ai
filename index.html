Comprehensive CLI Reference

Quick Command Guide

Explore every available option and flag built into the c2ai tool.

Standard Scan directory

Default Execution

Scans current directory, runs the DLP Guardian, counts tokens, and outputs to prompt.md.

c2ai .
Custom Output -o, output

Specify Output Path

Saves the consolidated markdown prompt to a custom file name (automatically normalizes to .md).

c2ai . -o custom_prompt.md
AI Guidance -i, instruction

Prepend Instruction

Injects custom instructions or directives right at the top of the generated Markdown prompt for LLMs.

c2ai . -i "Refactor to clean code"
File Filtering -e, files & extensions

Filter by Ext / Name

Filters files using comma-separated extensions or exact filenames (e.g., "py, js" or "main.py").

c2ai . -e "py, main.js, index.html"
Exclusion Control -exc, exclude-dir

Exclude Directories

Explicitly excludes specific folders, files, or extension types beyond default gitignore rules.

c2ai . -exc "tests, temp"
Dashboard Server --no-serve

Toggle HTML Server

Controls whether the local HTTP dashboard server is automatically launched after scanning (--no-serve disables it).

c2ai . -i "Refactor to clean code" --no-serve
